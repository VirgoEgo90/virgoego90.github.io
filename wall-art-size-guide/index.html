DPI is pixels divided by inches on each side. If the two sides differ, this page reports the lower figure, which is the limiting one. 300 DPI is the usual target for art viewed up close. 150–200 DPI can look fine on a larger poster seen from a few feet away. These are rules of thumb, not a guarantee from any particular printer.

How to use a print size and DPI calculator

  1. Find your image’s pixel width and height. In most photo apps this is under File → Properties, or you can open the file here. The file is not uploaded.
  2. Choose a print size, or tap a common frame size. The calculator shows the resulting DPI and whether the shapes match.
  3. If a size needs a crop, compare the aspect ratios. An 8×10 (4:5) and a 16×20 (also 4:5) share a shape; an 8×10 and an 11×14 do not.
  4. When you buy a print pack, look for files already prepared at 300 DPI in the sizes you want, so you do not have to resize them yourself.
