Spreadsheets guide

How to make a monthly budget in Google Sheets

By Ivan Dummett · Updated November 18, 2026

Try the free 50/30/20 calculator first

Google Sheets is free, works on a phone, and is flexible enough to hold a full monthly budget. You can build one yourself in under an hour. Here is a simple structure that scales from a single month to a full year.

1. Make a Categories tab

Create a sheet called Categories and list your spending categories down column A: Rent, Utilities, Groceries, Transport, Insurance, Dining out, Subscriptions, Gifts, Savings, and so on. Keep the list short at first. You can add more later.

This list powers the dropdowns in the next step, so you only ever type a category name once.

2. Build an expense log

On a sheet called Expenses, add the headers Date, Description, Category, and Amount. Then select the Category column and choose Data → Data validation, set the criteria to "Dropdown (from a range)," and point it at your Categories list. Now every expense row gets a dropdown, which keeps the totals accurate.

Format the Date column as a date and the Amount column as currency.

3. Add an income table

An Income sheet with Date, Source, and Amount is enough. If you have more than one paycheck or side income, each gets its own row.

4. Total each category with SUMIFS

Create a Summary sheet. Put the categories in column A (you can reference the Categories tab). In column B, total each category for one month with SUMIFS. If the month's first day is in cell B1, the formula looks like this:

=SUMIFS(Expenses!D:D, Expenses!C:C, A3,
        Expenses!A:A, ">="&$B$1,
        Expenses!A:A, "<"&EDATE($B$1,1))

It adds every amount in the Expenses sheet where the category matches and the date falls inside that month. Copy it down the column, then across for more months by changing the start date.

5. Compare with a plan

Next to each actual total, add a Planned column and a Difference column (=Planned − Actual). Conditional formatting makes overspending easy to spot: select the Difference column, choose Format → Conditional formatting, and set "Less than 0" to a soft red.

6. Add a chart

Select the category names and actual totals, then choose Insert → Chart. A bar chart is usually easier to read than a pie chart once you have more than five categories.

7. Make it a monthly routine

  • Log expenses once or twice a week rather than every day.
  • On the first of the month, copy the summary columns forward.
  • Look at the Difference column and decide one thing to adjust next month.

Common problems

My SUMIFS returns zero

Check that the dates are real dates, not text. Click a date cell: if it's left-aligned by default, it may be text. Retype it, or use Format → Number → Date.

The dropdown doesn't show new categories

Extend the validation range to cover empty rows below your list, such as Categories!A2:A100.
