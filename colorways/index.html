    How it works

    1. 01

      Pick a theme

      Start from night and gold, indigo fields, cold chrome, or a kente- or adire-inspired combination. These are working systems, not costumes.

    2. 02

      Lock and regenerate

      Each role — ground, field, accent, metal, trim — can be locked. Generate again to shuffle only what is still open.

    3. 03

      Read it on a body

      The one-piece updates live so you can judge proportion and shine the way you would on a real silhouette, not a flat chip.

    4. 04

      Take the codes

      Copy a single hex, copy the whole list, or export a PNG board for a lookbook, a tech pack, or a mood board.
