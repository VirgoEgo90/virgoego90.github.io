How to set a wallpaper

iPhone

Save the image to Photos, open it, tap Share → Use as Wallpaper, and pinch to fit.

Android

Open the image in Photos or Files, tap ⋮ → Use as → Wallpaper.

Desktop

Right-click the downloaded file and choose Set as desktop background (Windows) or Set Desktop Picture (Mac).
